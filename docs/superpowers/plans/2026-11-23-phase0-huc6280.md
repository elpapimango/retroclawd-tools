# Phase 0: HuC6280 in the tools

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans. Steps use checkbox (`- [ ]`) syntax.

**Goal:** assemble, disassemble and build PC Engine HuCards with the tools; the emulator's test cards are built by them.

**Architecture:** the HuC6280 core (now `shared/crates/core/huc6280` on the emulator's `pcengine` branch) moves to retroclawd-core as `rc-huc6280`
with a public disassembler. `rcasm` builds its HuC6280 encoding table by enumerating that disassembler (the way it does for the Z80, so there
is one source of truth), `rcdis` decodes with it, `rcld` writes the card.

**Tech stack:** Rust 2024; existing crates `rcasm`, `rcdis`, `rcld`.

**Spec:** `docs/superpowers/specs/2026-11-23-rcb-toolchain-design.md` (phase 0). **Roadmap:** `2026-11-23-rcb-roadmap.md`.

## Global constraints

Those of the roadmap. Specific here: HuC6280 mnemonics are the Hudson/PCEAS-documented ones (`TAM`, `TMA`, `TII`, `TDD`, `TIN`, `TIA`, `TAI`, `ST0`-`ST2`,
`SET`, `CSH`, `CSL`, `CLA`, `CLX`, `CLY`, `SAX`, `SAY`, `SXY`, `BSR`, `TST`, Rockwell `BBR0-7`/`BBS0-7`/`RMB0-7`/`SMB0-7`, `TSB`, `TRB`, `STZ`, `BRA`,
`PHX`, `PHY`, `PLX`, `PLY`); the assembler sees the 16-bit logical address space; zero page is logical `$2000-$20FF` and the assembler writes the low byte.

## Review focus

1. `TII`/`TDD`/`TIN`/`TIA`/`TAI` with symbols defined later (three operands, each 16 bits): sizes must not change between passes.
2. `BBRn zp,label` branches out of range: error naming the label and distance.
3. A card whose code crosses an 8 KB bank boundary or whose bank is not a power-of-two multiple: `rcld` error naming the symbol or piece.
4. `TST #imm,zp` versus `TST #imm,abs,X`: the zero-page and absolute forms chosen by operand size like the 6502.
5. A 2.5 MB card layout, a 384 KB card and an input smaller than 128 KB: sizes padded to what the emulator's card reader accepts.

### Task 1: the core in retroclawd-core

- [ ] Filter `shared/crates/core/huc6280` of the emulator's `pcengine` branch with its history into `retroclawd-core/crates/huc6280`; set package name `rc-huc6280`, `[lib] name = "huc6280"`, repository, readme and description as the other core crates.
- [ ] Test (in the crate): `disassemble_at(&[0x73, 0x00, 0x40, 0x00, 0x50, 0x10, 0x00], 0xE000)` returns `("TII $4000,$5000,$0010", 7)`; `disassemble_at(&[0x0F, 0x20, 0xFE], 0xE000)` returns `("BBR0 $20,$E001", 3)` (target = pc + 3 + offset).
- [ ] Implement `disassemble_at` as a public wrapper of the existing opcode table, one place for text; `cargo test -p rc-huc6280` passes.
- [ ] Commit; publish `rc-huc6280 0.1.0` once the 0.1 crates are all published.

### Task 2: rcasm, `Cpu::Huc6280`

**Interfaces:** consumes `huc6280::disassemble::disassemble_at`; produces `Cpu::Huc6280` (names `huc6280`, `65c02`-superset `pce`), `.cpu huc6280`, `-c huc6280`.

- [ ] Tests in `rcasm/tests/huc6280.rs`: every opcode `0..=255` decodes with `disassemble_at`, the text assembles back to the same bytes (exactly like `tests/roundtrip.rs` for the Z80); `tam #$01`, `tma #$80`, `st0 #$05`, `set`, `csh`, `clx`, `bsr lbl`, `tst #$12,$20`, `tst #$12,$2000,x`, `tii $4000,$5000,$0100`, `bbr3 $20,lbl`, `bbs7 $20,lbl`, `rmb4 $20`, `smb0 $20`, `stz $2000,x`, `bra lbl`, `sax`, `sxy`, `cla` assemble to the documented bytes (values listed in the test from `huc6280` core tests); `tii` with a forward symbol gives the same size on both passes; a branch out of range errors.
- [ ] Implement in `rcasm/src/huc6280.rs`: enumerate opcodes with filler bytes through `disassemble_at`, build `pattern -> Template` (slots: zero-page byte, byte, word, relative target, bit-branch pair); `encode(mnemonic, operand, site)` picks zero page versus absolute by operand size as the 6502 does; register in `cpu.rs` (`parse`, `name`, `is_mnemonic`, `encode`).
- [ ] `cargo test -p rcasm` passes (existing tests untouched).
- [ ] Docs: `docs/rcasm.md` HuC6280 section (syntax, block transfers, bit branches, zero page at `$2000`); commit.

### Task 3: rcdis

- [ ] Test: disassemble a 4 KB program with `jsr`, `bsr`, `bbr`, `jmp (abs,x)`, block transfers and data; output reassembles to identical bytes (`tests/roundtrip.rs` pattern); labels created for `BSR`, `BBRn/BBSn`, `BRA` and branch targets.
- [ ] Implement `Cpu::Huc6280` in `decode` and `flow` (`RTS`, `RTI`, `BRK` end flow; `BSR`, `JSR` call; `BBR`/`BBS` conditional with target); `--cpu huc6280`.
- [ ] Commit.

### Task 4: rcld, `machine = "pcengine"`

**Interfaces:** layout `machine = "pcengine"`, `cpu` implied; inputs may carry `bank = N` (8 KB bank number 0-127) with `at` inside `$E000-$FFFF` for bank 0 and the logical window otherwise; `[options] size = 131072` (pads to the size, rounded up to a multiple of 8 KB, power of two or 384 KB), `header = false`; vectors from symbols `reset` (default `start`), `irq2`, `irq1`, `timer`, `nmi` at `$FFF6-$FFFF` of the last bank-0 piece unless the layout writes them.

- [ ] Tests in `rcld/tests/pcengine.rs`: a one-bank program yields a 128 KB image with `start` in the reset vector at file offset `$1FFE`; `bank = 1` pieces land at offset `$2000` and up; a piece crossing a bank boundary errors naming the input; `size = 393216` accepted, `size = 100000` rejected; output extension `.pce` required.
- [ ] Implement `rcld/src/pcengine.rs` and `Machine::PcEngine` in `layout.rs`; `rcld template pcengine`.
- [ ] Docs `docs/rcld.md` HuCard section; commit.
